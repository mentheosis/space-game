# Space Hope To Achieve Iteration 3

Iteration 3 should make the new detail from iteration 2 easier to read in motion. The main ambition is not to add more random parts; it is to make surfaces, fixtures, and route edges compose better from the walkthrough camera.

## 1. Material Families

I want larger, more readable material zones in the cargo bay and cockpit. Iteration 2 added many fine elements, but some of them read as noise in motion. This pass should add broader contrast anchors: darker recessed equipment wells, warm worn floor lanes, pale removable panels, and metallic edge strips that organize the space from a moving camera.

## 2. Practical Lighting

I want the moving walkthrough to show visible sources and useful pools of light without depending on broad ambient fill. This pass should add or retune practical light fixtures so the ramp threshold, cargo centerline, side stairs, top landing, and cockpit seats remain readable during camera sweeps. It should also reduce frames where the camera looks into a nearly black void without useful interior context.

## 3. Ramp/Cargo Polish

I want the ramp and cargo area to read as an operational loading path. This pass should add larger cargo-bay organizing elements: side bumper rails, removable floor panels, threshold guide lights, equipment bay surrounds, and a clearer division between walkable cargo path and side machinery.

## 4. Cockpit Readability

I want the cockpit pilot station to be legible from the moving sweep: two seats, low consoles, hand controls, view direction, canopy sill, and floor route should all be recognizable without head-on favorable angles. This pass should lower visual clutter around the seat backs, add clearer low console surfaces, and use controlled light to separate the seats from the canopy and side panels.

## 5. Evidence Update

I want the material walkthrough to better support self-review. The route should still start at the ramp, walk to cargo center with left/right/up sweep, then continue up to the cockpit and repeat the sweep, but the camera should bias toward interior surfaces instead of losing too much time in empty exterior darkness. Static captures should keep the iteration 2 named views.

## Success Assessment Before Iteration 4

Iteration 3 was partially successful.

The material family target improved in static evidence: larger warm walk panels, dark gaps, green service panels, bumper rails, and lower shadow strips make the cargo bay easier to parse than the iteration 2 fine-detail layer alone.

The practical lighting target improved around the ramp and cargo path, with clearer guide lights and warmer side pools. It did not fully solve the moving walkthrough problem: the wide cockpit sweep still spends too many frames looking at dark canopy/side areas that do not usefully show the interior.

The ramp/cargo polish target improved. The cargo path now has broader organization, better side rail identity, and a clearer loading-lane feel. This is a good foundation for later art polish.

The cockpit readability target remains the weakest area. The added dashboard and console separation helps from static angles, but in the moving walkthrough the cockpit still becomes dark and repetitive from side/up sweep angles.

The evidence target improved only slightly. The static views are useful, but the moving walkthrough still needs to become a better diagnostic tool: the camera should include wide arcs while keeping cargo, stairs, seats, canopy sill, and floor route visible enough for review.
