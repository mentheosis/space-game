# Space Hope To Achieve Iteration 4

Iteration 4 should improve the cockpit and evidence loop rather than piling on more cargo detail. The cargo bay is now organized enough to serve as a base. The cockpit and moving walkthrough are the bottlenecks.

## 1. Material Families

I want the cockpit material language to become clearer: dark canopy seals, smoked glass, seat fabric, low dashboard metal, warm worn controls, and emissive displays should separate at a glance. This pass should use fewer but larger cockpit material shapes so the cockpit does not read as a collection of small blocks.

## 2. Practical Lighting

I want the cockpit sweep to have visible, believable sources that shape the seats and dashboard. This pass should add practical instrument glow, low footwell light, and small overhead/side fixtures that illuminate the seats and controls without flooding the canopy or turning the space flat.

## 3. Ramp/Cargo Polish

I want to keep the ramp/cargo path stable while adding only targeted polish: stronger threshold identity and a few larger cargo-panel accents that tie the ramp into the cargo bay. This pass should avoid adding visual clutter that competes with the cockpit work.

## 4. Cockpit Readability

I want the cockpit to read as two seats facing a real forward control station. This pass should improve the dashboard silhouette, reduce black block shapes near the chairs, add clearer control planes, strengthen the canopy sill, and make the forward floor/footwell route legible.

## 5. Evidence Update

I want the moving walkthrough to diagnose cockpit quality better. The route should still include the required ramp-to-cargo sweep and cockpit sweep, but the cockpit segment should move through a gentle arc instead of holding too many near-identical side frames. It should show seats, floor, dashboard, canopy sill, and side panels in one continuous review.

## Success Assessment Before Iteration 5

Iteration 4 improved the cockpit evidence loop but did not fully solve cockpit readability.

The material family target improved with larger cockpit dashboard, footwell, canopy-frame, and console surfaces. These made the cockpit less dependent on tiny details.

The practical lighting target improved with footwell, console, and seat rim lights. The cockpit seat area reads better in the moving walkthrough than iteration 3.

The ramp/cargo polish target stayed stable and gained threshold cues without adding major clutter.

The cockpit readability target is still only partially successful. The moving walkthrough now identifies the issue clearly: large dark console/seat masses dominate some side and oblique cockpit frames, especially around the forward dashboard and chair silhouettes.

The evidence target improved because the cockpit sweep now changes position and reveals the cockpit problem more clearly. Iteration 5 should use that evidence to reduce black mass dominance and improve the cockpit silhouette rather than adding unrelated cargo detail.
